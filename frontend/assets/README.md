# Frontend assets

`campus-hero.png` was generated for this project with the built-in image generation tool. Prompt:

> Use case: illustration-story. Asset type: wide homepage hero image for a clean student marketplace website. Primary request: a welcoming modern Vietnamese university campus, inspired by NEU in Hanoi but without official logos, with a light cream academic building, leafy trees, a few students walking, and clear blue sky. Style: polished editorial digital illustration, realistic architectural proportions, subtle painterly texture, bright natural morning light. Composition: landscape 16:9, building and people concentrated on the right half, ample clean pale blue sky and light open space on the left half for text overlay. Palette: vivid blue, pale sky blue, green, white. Constraints: no text, no logos, no watermark, no UI elements.

The product illustrations and favicon are original SVG assets in this directory.

`student-avatar.png` was generated for this project with the built-in image generation tool. Prompt:

> Use case: photorealistic-natural. Asset type: square avatar photo for a fictional student profile in a Vietnamese university marketplace website. Primary request: friendly Vietnamese university student in their early twenties, neutral cream shirt, natural warm expression, outdoors on a leafy campus. Style: realistic editorial portrait photography, polished but candid, no heavy retouching. Composition: centered head and shoulders, face clearly visible and suitable for circular crop. Lighting: soft bright daylight. Background: softly blurred trees and pale academic building. Constraints: fictional person, no visible brand marks, no text, no watermark, no UI.
